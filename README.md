# Habitr

A very simple habit tracker. Add a habit, tap a day to tick it off, see your streak.
Habits are saved in the browser (localStorage), so there is no database or sign-in.

## Files
- `index.html` - the page
- `styles.css` - the look (Bagr premium design)
- `app.js` - how it works

## Put it on GitHub and Vercel
1. Create a new repository on GitHub (for example `habitr`).
2. Upload `index.html`, `styles.css`, `app.js` and `README.md` to the top level of the repository (not inside a folder).
3. In Vercel choose Add New, then Project, and import the repository.
4. Leave every setting as it is (Framework Preset: Other) and press Deploy.

No build step is needed. Vercel serves the files as they are.
